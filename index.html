Instructions

Click to show or hide the guides

Import data

Choose the input format, then use Choose file or drag a .csv or .txt. Headers such as Strike, Dip, DipDir, Trend, Plunge, Set and Type are read automatically, in any column order. Without headers the first two numbers are used and a third value is the set name. Lines with errors are skipped and listed under the box.

Type data by hand

One measurement per line, for example 045, 30 or 120/65 J1. Separators can be comma, semicolon, tab, space or slash. Strike/Dip uses the right-hand rule: the plane dips to the right of the strike direction.

Select measurements

Click a pole, line or great circle on the net, or tick a row in the table. Shift+click a row selects every row between it and the last row you clicked. Select all and Clear selection work on switched-on sets only. Press Delete to remove the selection.

From all data

Uses every measurement of the switched-on sets. Each set is calculated on its own, so three sets give three mean planes or girdles. The density map puts all switched-on sets together. Derived results are left out.

From selection

Uses only the selected measurements, as one group, even when it mixes sets. Planes and lines are calculated apart. Results are drawn in blue.

Two items selected

Two planes give the intersection line, the angle and the bisector planes, and σ1, σ2, σ3 if they can be a conjugate fault pair. Two lines give the plane that contains both. A plane and a line on it give the rake.

Add a result to your list

+ Add puts a calculated plane or line in the table, in set Derived, with a note of where it came from. You can colour, hide, select or delete it. Derived results are not counted in All data, so they never change the set statistics.

Hiding is not deleting

The eye in the table hides a measurement on the net and the 3D view only. It still counts in every calculation. Only Delete removes it from the calculations. A set chip is different: switching a set off leaves it out of All data.

Colours and sets

Double-click a set name in the table to rename it or move the measurement to another set (with several rows selected, all of them move). Click the colour square in a row to change that measurement. With several rows selected, the new colour goes to all of them. Click a set chip above the table to switch the whole set on or off.

When a tool does not draw

A result is drawn only when it exists geologically: enough measurements, planes or lines that are not parallel, and the right shape of data (a cluster for a mean, a girdle for a fold axis). The line under each tool says what is missing.

Rotated grid

Turns only the background grid onto an axis, for example a fold axis, so planes that contain it fall on grid lines. Type the axis as trend/plunge and press Apply, or select two planes or one line. The data does not move.

3D view

Drag to rotate. Plan view matches the stereonet. Upper half shows or hides the glass top, and Bowl changes how transparent the lower hemisphere is. Dashed lines are in the upper hemisphere.

Data

Import a .csv or .txt file. Put each value in its own column: one for strike (or dip direction), one for dip and one for the set name. For lines use trend, plunge and set.
